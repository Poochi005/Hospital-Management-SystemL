# Hospital Management System — GitHub Pages replacement

## Important
This is a static HTML/CSS/JavaScript demo. It does not require Java, Maven, or MySQL.
Data is saved in each visitor's browser localStorage.

## Publish to GitHub Pages
1. Extract this ZIP.
2. Open the extracted `HMS_GitHub_Pages_Replacement` folder.
3. Upload the *contents of this folder* to the ROOT of the `Poochi005/Hospital-Management-System` repository. Do not upload the whole folder as a nested folder.
4. Confirm `index.html` is at repository root and these paths exist at repository root:
   - `css/style.css`
   - `js/local-api.js`
   - `js/common.js`
   - `js/login.js`
   - `admin.html`, `doctor.html`, `patient.html`
5. Commit and push the changes.
6. In GitHub: Settings → Pages, confirm the correct branch/folder is selected.
7. Wait for deployment, then hard refresh the site with Ctrl+Shift+R.
